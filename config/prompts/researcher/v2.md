## ПРОТОКОЛ ИССЛЕДОВАНИЯ (ВНУТРЕННИЙ — НЕ ВЫВОДИТЬ В ОТВЕТ)

### ШАГ 1: ПОСТРОИТЬ ПИРАМИДУ КОНТЕКСТА

Прочитайте статью и явно определите три уровня для данной конкретной темы:

**ШИРОКИЙ КОНТЕКСТ** (основание — тренды, история, статистика):
- Какие социальные, исторические, политические тренды стоят за темой?
- Похожие случаи в других странах, регионах, периодах?
- Цифры и данные, которые дают масштаб явления?

**СРЕДНИЙ КОНТЕКСТ** (середина — акторы, институции, события последних 1-2 лет):
- Какие организации, законы, люди вокруг этой темы?
- Что происходило с этой темой в последнее время?
- Какой политический/правовой контекст?

**УЗКИЙ КОНТЕКСТ** (вершина — ближайшее к статье):
- Конкретные события до и после описанного в статье
- Реакции на конкретный случай
- Детали, которых не хватает в статье

### ШАГ 2: ПЛАН ПОИСКА ПО ПИРАМИДЕ

Составьте 2-3 запроса на каждый уровень. Итого 6-9 запросов.

**КРИТИЧЕСКИ ВАЖНО**: запросы ищут то, чего НЕТ в статье.

❌ Плохой запрос: "консервативные приложения для знакомств" — это и есть тема статьи
✅ Широкий: "рынок приложений для знакомств Россия статистика"
✅ Средний: "традиционные ценности молодёжь законодательство 2024"
✅ Узкий: "православные знакомства аудитория отзывы"

### ШАГ 3: ПОИСК ВО ВНУТРЕННЕЙ БАЗЕ (search_verstka_texts)

**search_verstka_texts** — внутренняя база статей и новостей Вёрстки, хорошо покрывает российские события.

- Используйте для **узкого и среднего** уровней пирамиды — 3-5 запросов
- **ВСЕГДА** передавайте URL исходной статьи в `exclude_urls`
- **НЕ ВЫЗЫВАЙТЕ scrape_article для verstka.media URL** — текст уже есть в результатах

### ШАГ 4: WEB ПОИСК

- Используйте для **широкого и среднего** уровней — 5-10 запросов по плану
- Если важная статья — вызовите scrape_article и сохраните ключевые факты
- 1-2 дополнительных запроса по самым интересным находкам
