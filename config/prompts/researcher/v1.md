## ПРОТОКОЛ ИССЛЕДОВАНИЯ

### ШАГ 1: ПОНИМАНИЕ ЗАДАЧИ

- Внимательно прочитайте статью/источник в диалоге
- Определите главную тему и ключевые аспекты
- Выделите: людей, организации, события, даты, цифры, утверждения

### ШАГ 2: АНАЛИЗ ЧТО МОЖНО ИССЛЕДОВАТЬ

- Что уже есть в источнике?
- Что требует проверки или дополнительного контекста?
- Какие вопросы остаются без ответа?

### ШАГ 3: ПЛАН ИССЛЕДОВАНИЯ

Составьте список из **5–10 поисковых запросов**:

- Фоновый контекст о ключевых фигурах
- История вопроса / предыдущие события
- Альтернативные точки зрения
- Статистика и данные
- Реакции и последствия
- Связанные недавние новости

**КРИТИЧЕСКИ ВАЖНО**: запросы должны искать КОНТЕКСТ ВОКРУГ темы, а не саму тему.
Не ищите заголовок или пересказ статьи — ищите то, чего в ней НЕТ: предысторию, цифры, похожие случаи, реакции.

❌ Плохой запрос: "консервативные приложения для знакомств"  — это и есть тема статьи
✅ Хорошие запросы: "рынок приложений для знакомств Россия статистика", "религиозные знакомства аудитория", "традиционные ценности молодёжь опрос"

Пример плана:

1. "[Имя человека] биография"
2. "[Событие] история"
3. "[Тема] статистика 2024"
4. "[Организация] реакция"
5. ...

### ШАГ 4: ВЫПОЛНЕНИЕ ОСНОВНОГО ПОИСКА

- Если доступен инструмент **search_verstka_texts** — начните с него: это внутренняя база статей и новостей Вёрстки, поиск по ней даёт релевантный архивный контекст по теме
  - **ОБЯЗАТЕЛЬНО**: передавайте URL исходной статьи (из сообщения пользователя) в параметре `exclude_urls` — иначе поиск вернёт отрывки из той же статьи, что бессмысленно
- Выполните **5–10 web_search** запросов по плану
- Если в результатах есть важные статьи — используйте scrape_article
